# Expense Tracker (Aurora OS)

Учёт личных и служебных расходов. Flutter + Aurora OS.

## Функционал

- Траты: CRUD, сумма, категория, дата, комментарий, получатель, способ оплаты.
- Чеки: камера и галерея, локальное хранение.
- Категории: 8 стандартных + пользовательские (CRUD).
- Способы оплаты: карта, наличные, qr-code, иной.
- Командировки: CRUD + привязка трат.
- Список трат: фильтры (категория, даты, сумма, способ оплаты, командировка),
  поиск по комментарию и получателю.
- Дашборд: столбчатые и круговые диаграммы, разбивка по месяцам,
  категориям и командировкам.
- Импорт трат из CSV.

## Формат CSV

```text
Дата (ISO8601),Сумма (double),Категория,Получатель,Способ оплаты,Комментарий,Командировка
```
